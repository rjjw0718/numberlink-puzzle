# 📐 넘버링크: 수학적 논리 퍼즐 (Numberlink Logic Puzzle)

수학적 격자 위상학과 그래프 경로(Hamiltonian Path) 이론을 모티브로 제작된 웹 기반 **넘버링크(Numberlink / Flow)** 퍼즐 게임입니다.

---

## 🎮 게임 규칙 (Rules)

1. **같은 숫자 연결**: 격자 위에 놓인 같은 번호의 두 숫자를 하나의 연속된 선으로 연결합니다.
2. **선의 불교차 원칙**: 선은 교차하거나 겹칠 수 없으며, 하나의 작은 정사각형 격자 칸은 **단 한 번만** 지나갈 수 있습니다.
3. **완전한 빈칸 채우기 (전수 피복 - 핵심 규칙)**: 퍼즐이 완성되었을 때 **선이 지나가지 않는 빈칸이 단 하나도 남아서는 안 됩니다**. 격자의 모든 칸을 100% 가득 채워야 정답으로 인정됩니다!

---

## ✨ 주요 기능 및 특징

- 📐 **수학 테마 비주얼 & 애니메이션 배경**:
  - 직교 좌표계 그리드, 조화 파동 함수(Harmonic Wave), 부유하는 수학 공식($\sum, \int, \pi, e^{i\pi}+1=0, \nabla, \phi, \lim$ 등) 캔버스 배경
  - 세련된 다크 블루 & 일렉트릭 사이언 네온 글래스모피즘 UI
- 🖱️ **직관적인 조작감 (마우스 & 터치 완벽 지원)**:
  - 데스크톱 마우스 드래그 및 스마트폰/태블릿 터치 제스처 지원
  - 드래그 반대 방향으로 이동 시 자동으로 선이 되감기는 백트래킹(Backtracking) 지원
- 🔊 **자체 내장 사운드 신시사이저 (Web Audio API)**:
  - 외부 음원 파일 다운로드 없이 브라우저 자체 Web Audio API로 노드 터치음, 화음 연결음, 오답 알림, 승리 팡파르 구현
  - 사운드 On/Off 토글 지원
- 🔒 **단계별 해금 시스템**:
  - 총 16개의 정교한 스테이지 구성 (5×5 입문부터 10×10 최고난도까지)
  - 중간 난제(Stage 11) 및 최종 마스터(Stage 16) 2개의 고난도 퍼즐 포함
  - 각 단계를 통과해야만 다음 단계로 이동 가능
- 📋 **실시간 상태 표시**:
  - 연결된 숫자 쌍 개수, 격자 채움 비율(%), 스테이지 경과 시간 실시간 집계

## 🚀 깃허브(GitHub) 업로드 및 GitHub Pages 무료 배포 방법

본 프로젝트는 순수 HTML, CSS, JavaScript로 구현되어 있어 별도의 빌드 과정 없이 **GitHub Pages**를 통해 누구나 접속할 수 있는 웹사이트로 즉시 배포할 수 있습니다.

### 1단계: GitHub 새 저장소 생성
1. [GitHub](https://github.com)에 로그인 후 우측 상단의 **[+]** -> **[New repository]**를 클릭합니다.
2. Repository name에 `numberlink-game` 입력
3. **Public** 선택 후 **[Create repository]** 클릭

### 2단계: 로컬 파일 커밋 & 푸시
터미널(또는 Git Bash)에서 해당 폴더로 이동 후 아래 명령어를 실행합니다:

```bash
# 1. 프로젝트 폴더로 이동
cd numberlink-game

# 2. git 저장소 초기화
git init

# 3. 파일 전체 추가 및 첫 커밋
git add .
git commit -m "feat: 넘버링크 수학 퍼즐 16단계 게임 완성"

# 4. 기본 브랜치명을 main으로 설정
git branch -M main

# 5. 본인의 GitHub 저장소 원격 연결 (YOUR_USERNAME 자리에 본인 깃허브 아이디 입력)
git remote add origin https://github.com/YOUR_USERNAME/numberlink-game.git

# 6. 원격 저장소로 업로드
git push -u origin main
```

### 3단계: GitHub Pages 활성화 (웹사이트 공개)
1. GitHub 저장소 상단의 **[Settings]** 탭으로 이동합니다.
2. 좌측 메뉴에서 **[Pages]** 클릭
3. **Build and deployment** 항목의 **Branch**를 `main` 브랜치, 폴더를 `/(root)`로 지정 후 **[Save]** 클릭
4. 약 1~2분 후 상단에 생성되는 URL(예: `https://YOUR_USERNAME.github.io/numberlink-game/`)로 접속하면 전 세계 어디서든 웹 브라우저로 게임을 플레이할 수 있습니다!
